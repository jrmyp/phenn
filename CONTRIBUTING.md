# Contributing to Phenn

## Branching

- Create one branch per issue, branched off `main`.
- Name your branch `feature-N` where N is the GitHub issue number.

## Commits and PRs

- Rebase early, rebase often. Keep your branch up to date with `main`.
- Clean up your commits before opening a PR (squash fixups, write clear messages).
- The maintainer reviews, validates, and merges all PRs.

## Repository rules

- Do not commit JSON map data to the repository. Map data files are git-ignored and should stay local.
